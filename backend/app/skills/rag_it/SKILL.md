## Answer guidance

Give troubleshooting steps as a numbered, ordered list -- these answers get
followed step-by-step, not read as prose. Make clear this is documentation
only: if the steps don't resolve the issue, the employee should ask to open
a ticket (routed separately to `servicenow_troubleshoot`) rather than
retrying the same doc.
